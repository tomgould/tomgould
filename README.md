I lead the team behind Flow, the publishing system for newsrooms at [Bright Sites](https://www.brightsites.co.uk), and its back end is my design and my code. Away from work I build open-source libraries and tools, and write up how each one works on my site.

## Libraries and tools

- [Apple News API](https://github.com/tomgould/Apple-News-API): builds and publishes Apple News articles from PHP objects. Downloaded nearly 2,500 times from Packagist.
- [GitHub Auditor](https://github.com/tomgould/github-auditor): keeps local clones of whole GitHub and Bitbucket accounts and writes reports from them.
- [PrintMD](https://printmd.dealmobile.co.uk): designed PDFs from Markdown, plus Word and PowerPoint files. [Source on GitHub](https://github.com/tomgould/PrintMD).
- [TurboPush](https://github.com/tomgould/TurboPush): resumable chunked uploads from the browser to one PHP class.
- [RSS to JSON](https://github.com/tomgould/rss-to-json): feeds in, predictable JSON out, in PHP.
- [Puzzler PHP SDK](https://github.com/tomgould/PuzzlerPHPSDK): crosswords, sudoku and wordsearches from Puzzler Media, in PHP. Unofficial.
- [ScrapePy](https://github.com/tomgould/ScrapePy): offline copies of websites, with Markdown alongside.
- [Reelify](https://github.com/tomgould/Reelify): short summary videos from long screen recordings.
- [Scrape](https://github.com/tomgould/Scrape): parallel downloads from web server directory listings. My oldest public repository, from 2010. Archived.

## For fun

- [Where Should I Live](https://tax.dealmobile.co.uk): 78 cities ranked by what you'd keep after tax, what a month costs and which visas you could get.
- [Solar Calendar](https://solar.dealmobile.co.uk): a 13-month calendar in which the 1st is always a Monday. [Source on GitHub](https://github.com/tomgould/solar-calendar).
- [TCL Google TV Tools](https://github.com/tomgould/tcl-google-tv-tools): decluttering our TV over ADB without root, and using it as an extra screen for a Linux laptop.
