I've worked on the web since 2004. These are the apps, libraries and tools I've built in my own time. Most of them are open source.

## Apps

- [Where Should I Live](https://tax.dealmobile.co.uk): ranks cities around the world by what you'd keep after tax, what a month costs and which visas you can get. Closed source.
- [Solar Calendar](https://solar.dealmobile.co.uk): a calendar of 13 identical 28-day months, with each year starting on the first Monday on or after the spring equinox. [Source on GitHub](https://github.com/tomgould/solar-calendar).

## Libraries

- [Apple News API](https://github.com/tomgould/Apple-News-API): a PHP client for publishing articles to Apple News, with a document builder for the whole Apple News Format.
- [TurboPush](https://github.com/tomgould/TurboPush): uploads large files from the browser in chunks that survive dropped connections and page reloads, with a PHP endpoint that checks and reassembles them safely.
- [RSS to JSON](https://github.com/tomgould/rss-to-json): a small PHP library and command-line tool that turns RSS, Atom and media feeds into clean JSON.
- [Puzzler PHP SDK](https://github.com/tomgould/PuzzlerPHPSDK): an unofficial PHP client for the Puzzler Media puzzles API, with signed requests and clear errors.

## Tools

- [Mullet](https://github.com/tomgould/mullet-public): an AI coding orchestrator that sends each task to the cheapest model that can handle it, and plugs into Claude Code over MCP. Paused.
- [GitHub Auditor](https://github.com/tomgould/github-auditor): a command-line tool for looking after a lot of GitHub repositories at once, with reports on their health, on who has access and on what each developer did.
- [ScrapePy](https://github.com/tomgould/ScrapePy): a Python web scraper that saves whole sites for offline reading and can turn them into Markdown.
- [Trove](https://github.com/tomgould/trove): a local knowledge engine that searches documents and code by keyword and by meaning, for AI coding tools. Archived in favour of Mullet.
- [Scrape](https://github.com/tomgould/Scrape): a PHP class that downloads files from web servers with directory listings turned on, and my oldest public repository. Archived.

## Experiments

- [Reelify](https://github.com/tomgould/Reelify): turns long screen recordings into short summary videos, by cutting idle time and speeding up what's left to fit a target length.
